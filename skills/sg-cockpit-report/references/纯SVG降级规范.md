# 纯 SVG 降级规范（ECharts 不可用时）

> 适用：明鉴（sg-insight）产出的所有 HTML 可视化报告
> 范本：`sg-cockpit-report` 生成的《三钢集团生产经营驾驶舱报告》（8 张 SVG / 0 依赖 / 231KB）

## 一、触发条件（命中任一即启用本规范）

| # | 条件 | 判定方法 |
|---|---|---|
| 1 | 用户明示「不能用 ECharts / 要零依赖 / 内网无 CDN / 离线打开」 | 语义判定 |
| 2 | 目标环境无法内联 1MB 的 `echarts.min.js`（文件体积上限、嵌入渠道限制） | 用户告知或渠道约束 |
| 3 | 交付物需在受限终端打开（政企内网、老旧浏览器、邮件附件预览） | 场景判定 |
| 4 | ECharts 内联后仍渲染失败（控制台报错 / 空图表） | 验收 D2 失败后改走本规范 |

**不触发**：环境正常且无体积/依赖限制 → 仍按 `report_rules.md` 用内联 ECharts（交互更丰富）。

## 二、技术约束（硬性，缺一即不合格）

| # | 约束 | 校验 |
|---|---|---|
| T1 | 图表全部用**内联 `<svg viewBox>`**，不用 `<canvas>` | `grep -c "<canvas"` = 0 |
| T2 | 零外部资源 | `grep -c "http://\|https://\| src="` = 0 |
| T3 | 图表库零引用 | `grep -c "echarts\|Chart.js\|highcharts\|d3.js"` = 0 |
| T4 | 样式内联 `<style>`，交互内联 `<script>`（可 0 个 script） | — |
| T5 | 单文件可离线双击打开 | 断网打开验证 |
| T6 | 每张 SVG 带 `role="img"` + `aria-label` | — |

## 三、图元映射（ECharts → 纯 SVG）

| ECharts 类型 | 纯 SVG 实现 | 范本位置 |
|---|---|---|
| 折线（趋势） | `<polyline>` + `<circle>` 打点 + 网格 `<line>` | `trend_prod()` |
| 柱状（对比） | `<rect rx="3">` + 顶部数值 `<text>` | `barchart()` |
| 双 Y 轴 | 左右各一套刻度 + 同 `X()` 函数共享 x 映射 | `trend_cost()` / `trend_month()` |
| 堆叠/分组柱 | 同 slot 内并列 `rect`，宽度 `slot*0.28` | `std_bar()` |
| 分歧条（正负） | 以 0 为轴的左右对称 `rect`，负绿正红 | `std_chart()` |
| 热力矩阵 | 网格 `rect` + `fill-opacity` 映射强度 | `heatmap()` |
| 饼/环图 | 用**占比条**替代（`rect` 宽度=占比），并在图注说明 | — |
| 散点 | `<circle r="3">` 直接定位 | — |
| 帕累托 | 柱 + 累计折线双轴组合 | — |

**不可降级项**（如实声明，不硬凑）：
雷达图 / 桑基图 / 地图 / 力导向图 → 改用**表格 + 一句结论**，并在图注写"原图类型：xxx，当前环境不支持，已改为表格呈现"。

## 四、样式令牌（直接复用驾驶舱，保证视觉一致）

```css
:root{
  --bg:#070b16; --panel:#0f1830; --panel2:#13203c; --line:#22304f;
  --txt:#e6edf7; --mut:#8b9bb4;
  --cyan:#2de2e6; --amber:#ffb02e; --blue:#4d9fff; --green:#39ff14; --mag:#ff2e97;
}
```

| 元素 | 规格 |
|---|---|
| 页面 | `max-width:1180px`，深色径向渐变底 |
| 卡片 | `background:var(--panel)` + `1px solid var(--line)` + `radius 14px` + `padding 18px` |
| 章节标题 | `20px/800`，左侧 `4px solid var(--cyan)` 竖条，`padding-left:12px` |
| KPI 卡 | 数值 `27px/800`，单位 `13px`，角标 `真实·DB2` |
| 明细表 | `border-collapse`，表头 `background:#16203a`，`font-size:12.5px` |
| 数值配色 | 利好 `--green`，不利 `--mag`，关注 `--amber` |
| 下钻抽屉 | `position:fixed` 右侧 560px 滑出 + 遮罩 + ESC 关闭 |

> ⚠ **成本域语义反转**：成本类指标"降为好、升为坏"，颜色与箭头必须与生产类指标相反。

## 五、结构模板（10 段，可按任务裁剪）

```
① 数据声明条（真实/口径边界两行）
② Hero（标题 + 账期 + 一句话结论）
③ KPI 网格（3~4 张，含角标与环比）
④ 核心图表区（1~2 张 SVG + 图注）
⑤ 口径说明卡（数据来源 / 对比规则 / 本期结论 三栏）
⑥ 明细表（数值单元格可点击下钻）
⑦ 分层策略/建议卡
⑧ 勾稽或交叉校验表
⑨ 数据质量提示（异常点逐条说明）
⑩ 脚注（血缘表名 / 未出数项 / 置信度 / 验收声明）
```

## 六、下钻要求（沿用 D1~D5，不因降级而豁免）

| # | 要求 | 标准 |
|---|---|---|
| D1 | `id="drill-drawer"` / `id="drill-overlay"` / `dwBody` / `dwCrumb` | 4/4 |
| D2 | `onclick="openDrillL1(` ÷ 明细表 `<td>` | ≥90% |
| D3 | `lv===1..4` 四层分支 | 齐全 |
| D4 | L4 源表明细行 | ≥10 行真实数据 |
| D5 | L2 含「Σ构成项」「落库分子」+ 差额 | 齐全 |

> 降级只换**渲染技术**，不降**可追溯性**。

## 七、验收清单（落盘前逐条打勾）

1. `grep -c "<canvas"` = 0
2. `grep -c "echarts\|Chart.js\|highcharts\|d3.js"` = 0
3. `grep -c "http"` = 0
4. `<svg` 数量 = 正文声明的图表数
5. 每张 SVG 坐标不越界（viewBox 内）
6. KPI 数值与数据集逐项一致
7. 明细表下钻覆盖率 ≥90%
8. L4 明细 ≥10 行
9. 异常数据已显式披露
10. 不可降级图表类型已声明替代方式
11. 断网双击可正常打开
12. 文本零"演示/合成"正向表述

## 八、成本与取舍（如实告知用户）

| 维度 | ECharts 版 | 纯 SVG 版 |
|---|---|---|
| 文件体积 | +1MB 库 | 约 200~250KB（纯数据+SVG） |
| 交互 | 缩放/悬浮提示/图例切换 | 仅下钻抽屉（无悬浮 tooltip） |
| 依赖 | 库需内联 | 零依赖 |
| 图表类型 | 全类型 | 折线/柱/双轴/热力/分歧条/散点够用，雷达·桑基·地图不支持 |
| 移动端 | 支持 | 支持（响应式 viewBox） |
