## 一、生产域（GZPROD）

### 钢材产量

```sql
SELECT YMD, ZB_CODE, ZB_VALUE
FROM SMBB_M_S_ZZ00.T_DWS_FACT_ZZGZ_0002
WHERE YMD = '20261029'
  AND ZB_CODE IN ('1600014','1600057','1600058',   -- 日产量：本部/泉州/罗源
                  '1600026','1600061','1600062');  -- 月累计
```

| 基地 | 日产量 ZB | 月累计 ZB |
|---|---|---|
| 本部（三明闽光） | 1600014 | 1600026 |
| 泉州（泉州闽光） | 1600057 | 1600061 |
| 罗源（罗源闽光） | 1600058 | 1600062 |

> ⚠ **陷阱**：`FACTORY_DIV` 存的是产线组合串（如 `21+22+23+51+52+31日`），按厂别编码过滤会跨基地混数。必须按 ZB_CODE 取。

### 粗钢产量

```sql
SELECT FACTORY_DIV, ZB_CODE, ZB_VALUE
FROM SMBB_M_S_ZZ00.T_DWS_FACT_ZZGZ_0003
WHERE YMD = '20261029' AND FACTORY_DIV IN ('11+12','13','14');
```

`11+12`=本部、`13`=泉州、`14`=罗源；ZB_CODE 1600013 / 1600049 / 1600050。

### 钢铁料耗 / 铁水耗

```sql
SELECT YMD, FACTORY_CNAME, ZB_CODE, ZB_VALUE
FROM SMBB_M_S_ZZ00.T_DWS_FACT_ZZGZ_LG01
WHERE YMD = '20261029'
  AND (ZB_NAME LIKE '%钢铁料耗%' OR ZB_NAME LIKE '%铁水耗%');
```

| 基地 | 钢铁料耗 ZB | 铁水耗 ZB |
|---|---|---|
| 本部 | 1600213 | 1600207 |
| 泉州 | 6012800 | 6038900 |
| 罗源 | 5000106 | 5000104 |

> ⚠ **陷阱**：`FACTORY_CODE` 常为空字符串，必须用 `FACTORY_CNAME IN ('三明炼钢','泉州炼钢','罗源炼钢')` 分组。

## 二、成本域（CBPROD，仅本部）

```sql
-- 吨材成本（日）
SELECT ACCOUNT_PERIOD, DAY_ALL_VAL
FROM SMBB_M_A_CB01.T_ADS_SRV_CACA_DAY_COST
WHERE ITEM_NAME2 = '吨材成本' AND ITEM_UNIC = '元/吨'
  AND ACCOUNT_PERIOD BETWEEN '20261016V1' AND '20261029V1'
ORDER BY ACCOUNT_PERIOD;

-- 吨材成本（月，CBCX06 = 6.钢材）
SELECT ACCOUNT_PERIOD, MONTH_CONSUME, MONTH_COST,
       MONTH_COST / NULLIF(MONTH_CONSUME,0) AS UNIT_COST
FROM SMBB_M_A_CB01.T_ADS_SRV_CACA_MAIN_COST
WHERE ITEM_CODE = 'CBCX06' AND ACCOUNT_PERIOD BETWEEN '202604' AND '202609';
```

> ⚠ **陷阱**：`DAY_COST` 存在脏值 `ACCOUNT_PERIOD = 'LD      V1'`（54 行残留模板，值 3,307.34），不限定日期区间会把模板值当最新值。

## 三、标准成本 vs 实际成本（本技能核心新增）

```sql
-- 标准成本 / 日成本：同一张表按「版本」维度切分
SELECT "版本", "工序", "工序别名", "分类", "值"
FROM SMBB_M_S_CB00.T_DWD_FACT_CACA_DMXCBLR_GX
WHERE "时间" = '20261029'
  AND "分类" = '工序单位成本'
ORDER BY "版本", "工序";

-- 工序产量（仅日成本版本维护）
SELECT "版本", "工序", "值"
FROM SMBB_M_S_CB00.T_DWD_FACT_CACA_DMXCBLR_GX
WHERE "时间" = '20261029' AND "分类" = '工序产量';
```

### 口径定义

| 要素 | 定义 |
|---|---|
| 表 | `SMBB_M_S_CB00.T_DWD_FACT_CACA_DMXCBLR_GX`（列名全中文，必须双引号） |
| 日期列 | `"时间"`（字符串 YYYYMMDD），**无 `YMD`** |
| 切分 | `"版本"` ∈ {`标准成本`, `日成本`}，同表同口径 |
| 分类 | `"分类"` = `工序单位成本` / `工序总成本` / `工序产量` |
| 差异 | 实际 − 标准（负=节约，正=超支） |
| 成本影响 | 差异 × 当日工序产量 ÷ 10000（万元/日） |
| 可比性 | 标准版 9 工序、日成本版 11 工序，交集 8 |

## 四、存货域（存货日管控）

```sql
-- 本部（原燃料，KC_AMT=万元）
SELECT DATE_CODE, SUM(KC_WT) AS WT, SUM(KC_AMT) AS AMT
FROM SMBB_M_S_ZZ00.T_DWD_FACT_ZZCH_ZH_YLKC_ABNL
WHERE DATE_CODE = '20261029' GROUP BY DATE_CODE;

-- 泉州（原燃料，KC_AMT=万元）
SELECT DATE_CODE, SUM(KC_WT) AS WT, SUM(KC_AMT) AS AMT
FROM SMBB_M_S_ZZ00.T_DWD_FACT_ZZCH_ZH_YLKC_ABNL_QZ
WHERE DATE_CODE = '20261029' GROUP BY DATE_CODE;

-- 罗源（原料，INV_AMT=元 → ÷10000 折万元）
SELECT DATE_CODE, SUM(INV_WT) AS WT, SUM(INV_AMT)/10000 AS AMT
FROM SMBB_M_S_ZZ00.T_DWD_FACT_ZZCH_ZH_YRL_LY
WHERE DATE_CODE = '20261029' GROUP BY DATE_CODE;
```

> ⚠ 罗源是"原料"（不含燃料），本部/泉州是"原燃料"（含燃料）→ 集团加总属**非完全同口径**，报告须显式声明。
