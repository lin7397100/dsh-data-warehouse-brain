# sg-cockpit-report · 生产经营驾驶舱报告

## 定位

把"给领导看的一屏经营总览"做成**可复算、可下钻、可离线打开**的单文件 HTML。

覆盖四域：**生产管制（GZPROD）／成本（CBPROD）／存货日管控／标准成本 vs 实际成本对比**。

> 🚨 **路由铁律**：用户消息含「驾驶舱」类关键词 → **必走本技能**，禁止走 `sg-kanban-builder`（那是通用看板，无勾稽闸门）或 `sg-report-composer`（那是通用报告，无四域口径）。

## 触发词（命中任一即触发）

| 优先级 | 触发词 |
|---|---|
| P0 强触发 | `驾驶舱报告`、`生产经营驾驶舱`、`生成驾驶舱`、`集团经营驾驶舱`、`cockpit` |
| P1 等同触发 | `领导驾驶舱`、`经营总览`、`一屏经营`、`驾驶舱 + 标准成本` |
| P2 组合触发 | 同时出现「生产 + 成本 + 存货」三域 + 「一屏/总览/报告」 |

**不触发**：单纯"看板/仪表盘"→ `sg-kanban-builder`；单纯"生成报告"→ `sg-report-composer`；纯数值问数 → 快车道。

## 输入

| 参数 | 必填 | 说明 |
|---|---|---|
| 账期 `period` | ✅ | `YYYYMMDD`，如 `20261029` |
| 环比基期 | ❌ | 默认取账期前一自然日 |
| 数据集路径 | ❌ | 默认 `data/cockpit_data_<period>.json` |
| 输出路径 | ❌ | 默认 `<workspace>/三钢集团生产经营驾驶舱报告.html` |

## 执行步骤（5 步，不可跳）

### Step 1 · 取数（DB2 MCP 只读）

按 `references/口径与血缘.md` 的 SQL 逐条实取。**四个必须遵守的取数纪律**：

1. **不写 `FETCH FIRST`** —— 工具会自动追加，冲突报 SQLCODE=-104
2. **钢材产量按 ZB_CODE 取**（1600014/1600057/1600058），`FACTORY_DIV` 是产线组合串，按厂别过滤会跨基地混数
3. **料耗用 `FACTORY_CNAME` 分组**，`FACTORY_CODE` 常为空
4. **标准成本用 `T_DWD_FACT_CACA_DMXCBLR_GX` 的 `版本` 维度**，中文列名必须双引号

### Step 2 · 写数据集

把结果写入 `data/cockpit_data_<period>.json`，至少含 5 段：`meta` / `production` / `cost` / `inventory` / `standard_cost`。
**禁止**在脚本里内嵌数字；数据集是唯一事实源（换账期只换 JSON）。

### Step 3 · 跑闸门（fail-fast）

```bash
python scripts/gen_cockpit.py --data data/cockpit_data_<period>.json --check
```

**36 项勾稽断言**，任一不通过则 `exit 1` 且**不落盘**。分组：

| 组 | 项数 | 代表断言 |
|---|---|---|
| 点值一致性 | 9 | 钢材/料耗/粗钢 各基地「点值 = 序列末值」 |
| 三基地求和 | 2 | Σ基地钢材 = 集团；Σ基地粗钢 = 集团 |
| 量纲合理性 | 4 | 材钢比 ∈[0.9,1.2]；料耗 > 铁水耗；加权值落在基地极值区间 |
| 月度闭合 | 2 | 总成本 ÷ 产量 = 吨材成本（容差 0.5%） |
| 存货 | 3 | Σ基地 = 集团；环比自洽；趋势末值 = 各基地资金 |
| 序列长度 | 7 | 各序列长度 = 日期轴长度 |
| **标准成本对比** | 10 | 可比工序 ≥6、差异率 ≤±50%、成本影响 = Σ逐项、净影响 = 实际总成本−标准总成本、不可比项已披露 |

### Step 4 · 渲染

```bash
python scripts/gen_cockpit.py --data data/cockpit_data_<period>.json --out <output.html>
```

产物硬约束：单文件 / 零外链 / 内联 CSS+JS+SVG / 无 CDN。

### Step 5 · 产物验收

```bash
python scripts/verify_cockpit.py --html <output.html> --data data/cockpit_data_<period>.json
```

必须 **ALL PASS**（含 D1~D5 下钻闸门）。

## 标准成本对比模块 · 口径（必须原样呈现，不得简化）

| 要素 | 定义 |
|---|---|
| **数据来源** | `SMBB_M_S_CB00.T_DWD_FACT_CACA_DMXCBLR_GX`，`时间='<账期>'`，`分类='工序单位成本'` |
| **切分方式** | 同一张表按 `版本` 维度取 `标准成本` 与 `日成本` 两组，**非跨表拼接** |
| **产量来源** | 同表 `分类='工序产量'`（仅日成本版本维护，产量无版本概念） |
| **差异** | 实际 − 标准（**负=节约，正=超支**） |
| **差异率** | 差异 ÷ 标准 |
| **成本影响** | 差异 × 当日工序产量 ÷ 10000（万元/日） |
| **可比性** | 标准成本仅维护 9 个工序、日成本 11 个，交集 8 个；**不可比项必须单列披露，禁止按 0 处理** |
| **判读红线** | 单工序 |差异率| > 15% 时，先疑"标准定额未重估"，不得直接认定为降本成效 |

> 本表为驾驶舱场景摘要；**通用下钻定义（触发条件/层级路径/口径/数据范围/输出格式）以手册为准**。

| # | 校验项 | 标准 | 本技能实测 |
|---|---|---|---|
| D1 | DOM 存在性 | `id="drill-drawer"` / `id="drill-overlay"` / `dwBody` / `dwCrumb` 四者齐备 | 4/4 ✅ |
| D2 | 绑定覆盖率 | `onclick="openDrillL1(` ÷ 明细表 `<td>` | 100%（226/226），全文 96.6% ✅ |
| D3 | 四层分支 | `lv===1` / `lv===2` / `lv===3` / `lv===4` | 4 层齐全 ✅ |
| D4 | L4 明细行数 | ≥10 行真实数据（非只贴 SQL） | 最小 14 行（std 16 / cost 14 / prod 30）✅ |
| D5 | 闭合校验展示 | L2 内同时出现「Σ构成项」「落库分子」+ 差额判定 | 齐全，差额 0 ✅ |

## 失败处理

| 现象 | 处置 |
|---|---|
| 闸门 FAIL | **停止**，修数据集或修断言；**禁止**注释掉断言绕过 |
| 某指标当日无数据 | 该指标从数据集移除并在报告"未出数项"披露，**禁止**填 0 |
| 标准成本版本缺工序 | 进 `not_comparable` 并写明原因，**禁止**按 0 参与加权 |
| 数据质量异常（如金额骤降） | 保留原值 + 在"数据质量提示"显式说明，**禁止**平滑/剔除 |
