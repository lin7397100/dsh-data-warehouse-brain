# sg-multi-factory-compare · 多厂对标

## 定位

横向比较三钢闽光 / 泉州 / 罗源 —— 但**必须先解决"可比性"**再谈差距。

## 对标三前提（P0）

| 前提 | 检查 | 不通过处置 |
|---|---|---|
| ① 口径一致 | 同一指标在各厂口径是否一致（单位/统计范围/剔除规则） | 不一致 → 说明差异，或改用可比口径 |
| ② 结构可比 | 品种结构、产能规模、产线配置是否可比 | 差异大 → 归一化（单位成本、单位能耗）或分组对标 |
| ③ 时间可比 | 对比区间是否含各自的检修/限产期 | 含异常期 → 标注或剔除后重算 |

## 对标方式

| 方式 | 适用 | 说明 |
|---|---|---|
| 绝对值对标 | 规模类指标 | 产量、消耗总量（需说明产能差异） |
| **单位值对标**（推荐） | 效率与成本类 | 吨钢成本、工序能耗、单耗、成材率、作业率 |
| 排名对标 | 多厂排序 | 标明排名维度与样本 |
| 差距分解 | 找出差距来源 | 按品种/工序/成本项逐级分解 |

## 工作流（四步）

### Step 1 · 确定对标维度与指标

指标 + 维度（工序 / 品种 / 成本项）+ 时间区间 + 厂部清单。

### Step 2 · 可比性校验（逐项过三前提）

输出可比性结论：完全可比 / 部分可比（说明限制）/ 不可比（建议改口径）。

### Step 3 · 对标计算

- 计算各厂值、均值、极差、最优/最差
- 计算本厂与均值/最优的差距（绝对 + 百分比）
- **差距分解**：差距主要来自哪个品种/工序/成本项

### Step 4 · 结论与建议

| 结论 | 要求 |
|---|---|
| 差距定位 | "本厂吨钢成本高于泉州 128 元，其中 72 元来自炼铁工序" |
| 优势项 | 明确指出哪些指标领先（对标不是只找差距） |
| 可借鉴点 | 差距项对应的最优厂做法（如有数据支撑） |
| 限制说明 | 产能/结构/口径差异对结论的影响 |

## 输出规范

```json
{"metric": "吨钢成本", "period": "2026-08", "unit": "元/吨",
 "comparability": {"口径": "一致", "结构": "部分可比（品种结构差异 ±12%）", "时间": "均剔除检修期"},
 "values": {"三钢闽光": 3250, "泉州": 3122, "罗源": 3180},
 "gap": {"vs 最优": "+128 元 (+4.1%)", "主要来源": "炼铁工序 72 元 / 能源 34 元 / 其他 22 元"},
 "strengths": ["成材率领先 0.8pp"],
 "limits": ["罗源 8 月含 5 天检修，已剔除"]}
```

## 注意事项

1. **不可比就不比** —— 强行对比产能差异大的绝对值指标会得出误导结论。
2. 优先用单位值（吨钢成本、单耗、能耗）对标，绝对值仅作参考。
3. 成本域语义反转：成本"排名靠前"需明确是数值高还是表现好，避免歧义。
4. 对标结论中的"差距来源"必须用数据分解支撑，不臆断。
