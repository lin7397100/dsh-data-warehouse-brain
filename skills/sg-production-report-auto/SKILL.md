# sg-production-report-auto · 生产报表自动汇总（生产轮）

## 定位

把"每天手工跑 N 条 SQL 拼 Excel"变成**一次触发、自动成报**。

## 五步流程

### Step 1 · 模板加载

按厂部/产线组织 KPI 集合，模板引用 `T_ADS_DIM_GZ01` 指标清单。

**模板结构**：

```json
{"template_id": "SG_DAILY_001", "name": "本部经营日报（生产轮）",
 "scope": {"factory": "三钢闽光", "period_type": "daily"},
 "sections": [
   {"name": "烧结", "metrics": [{"zb_code": "…", "zb_name": "…", "unit": "吨"}]},
   {"name": "炼铁", "metrics": [。.]},
   {"name": "炼钢", "metrics": [。.]},
   {"name": "轧钢", "metrics": [。.]}]}
```

### Step 2 · 批量 DSL 编译

全部 KPI 交开发专家批量编译（`sg-dsl-compiler`）：日期参数统一展开（`$TD$`）、口径版本统一、guards 逐项应用。

**批量优化**：同表同粒度的指标尽量合并 SQL（减少扫描次数），不同粒度的分开执行。

### Step 3 · 批量执行（DB2 MCP）

- 逐条或合并执行，收集结果
- 执行失败的指标**单独标注**，不中断整体流程
- 记录每个指标的执行耗时与返回行数

### Step 4 · Agentic 质量把关

对每个 KPI 值做异常检测（`sg-anomaly-detect`）：

| 情况 | 处置 |
|---|---|
| 空值 / 缺数 | 标注 + 触发缺数根因 |
| 偏离基线 | 标注偏离幅度 + 可跳转根因分析 |
| 与关联指标勾稽不符 | 标注矛盾点（如产量与消耗方向不一致） |

### Step 5 · 渲染交付

按模板渲染：

```
【本部经营日报 · 生产轮】2026-09-01
━━━━━━━━━━━━━━━━━━━━━━━
■ 烧结
  烧结矿产量   12,500 吨   环比 +2.1%  ✓
  烧结机作业率  96.2%       环比 -0.4%  ✓
■ 炼铁
  铁水产量     18,300 吨   环比 -8.0%  ⚠ 偏离基线（当日 2#高炉检修）
  焦比         365 kg/t    环比 +1.2%  ✓
…
异常项：2 项（铁水产量 / 轧钢作业率）→ 可展开根因分析
```

## 报表类型

| 类型 | 粒度 | 对比维度 |
|---|---|---|
| 日报 | 当日 | 环比（较前一日）+ 月累计进度 |
| 周报 | 本周 | 周环比 + 周计划完成率 |
| 月报 | 本月 | 月环比 + 月预算/计划对标 |

## 输出规范

- 报表正文（按模板分节，含数值 + 单位 + 环比 + 异常标注）
- 口径摘要（各指标口径要点，可折叠）
- 异常清单（含转根因分析入口）
- 数据限制说明（未过闸门的指标标注）

## 注意事项

1. **缺数不许填 0** —— 缺数标注为"无数据"，与真实 0 严格区分。
2. 异常指标必须给出业务上下文提示（检修/限产/品种切换），避免误读。
3. 报表模板变更需版本化，历史报表要能按当时模板复现。
4. 推送属外部动作（通知 MCP），执行前必须向用户确认接收方。
