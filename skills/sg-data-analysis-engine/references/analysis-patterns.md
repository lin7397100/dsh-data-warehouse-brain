# 分析方法选型速查

## 问题 → 方法

| 业务问题 | 方法 | 技能 |
|---|---|---|
| 数值是多少 | 指标查询 | `sg-nl2sql-query` |
| 变了多少 | 同环比 | `sg-trend-analysis` |
| 正不正常 | 异常检测 | `sg-anomaly-detect` |
| 为什么不对 | 根因分析 | `sg-root-cause-fullchain` |
| 成本为什么涨 | 三因子分解 | `sg-cost-ops` |
| 各厂谁更好 | 多厂对标 | `sg-multi-factory-compare` |
| 两组有差异吗 | 假设检验 | `sg-analysis-engine` |
| A 与 B 相关吗 | 相关性分析 | `sg-analysis-engine` |
| 下月会怎样 | 时间序列预测 | `sg-analysis-engine` |

## 统计检验选择

| 场景 | 检验 |
|---|---|
| 两组均值比较（正态） | 独立样本 t 检验 |
| 两组均值比较（非正态） | Mann-Whitney U |
| 多组均值比较 | 单因素方差分析（ANOVA） |
| 分类变量关联 | 卡方检验 |
| 相关关系（线性） | Pearson |
| 相关关系（单调非线） | Spearman |

**铁律**：相关 ≠ 因果；样本不足不给显著性结论。

## 归因分解

| 方法 | 适用 |
|---|---|
| 量-价-结构三因子 | 成本变动（本团主力方法） |
| 连环替代法 | 多因素顺序影响 |
| 贡献度分解 | 分项对总差异的贡献 |

## 预测方法

| 方法 | 适用 | 注意 |
|---|---|---|
| 移动平均 | 平稳序列 | 滞后性 |
| 指数平滑 | 有趋势无强季节 | 需选平滑系数 |
| 季节性分解 | 明显周期 | 需 ≥2 个完整周期 |
| 回归（含外生变量） | 有明确驱动因素 | 需说明变量选择 |

**预测必给置信区间与假设条件**，不承诺点预测准确。
