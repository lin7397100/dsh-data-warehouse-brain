# 安全与合规底线

## SQL 安全

| 层 | 底线 |
|---|---|
| 语法级 | 拦截 DROP / TRUNCATE / DELETE / ALTER / GRANT / INSERT / UPDATE / MERGE |
| 资源级 | 超时 ≤30 分钟、行数 ≤1 亿、大表必带分区条件、明细必带 FETCH FIRST |
| 权限级 | 只读服务账号，禁止跨授权 Schema |
| 审批级 | 任何写操作必须人工明确确认 |

## 数据分级

| 级别 | 范围 | 管控 |
|---|---|---|
| L4 | 成本明细、成本中心成本、产品毛利、采购价格 | 白名单 + 脱敏 + 全量审计 |
| L3 | 生产经营指标、消耗、能源、质量 | 限权 + 审计 |
| L2 | 产量、作业率、成材率 | 内部可用 |
| L1 | 已公开统计口径 | 无限制 |

**默认**：成本数据 = L4；未分级新表按 L3 从严。

## 脱敏方式

聚合化 / 区间化 / 相对化 / 遮挡（详见 `sg-data-classification`）。

## 代码执行

| 项 | 规范 |
|---|---|
| 环境 | 隔离 venv，禁止全局 pip install |
| 外部文件 | 邮件/下载来源视为不可信，**只保存不执行** |
| 凭据 | 不写入技能文件与脚本，走 MCP 配置或环境变量 |
| 可复现 | 脚本落盘 + 固定随机种子 |

## 外发与通知

| 项 | 规范 |
|---|---|
| 通知 MCP | Agentic 判断后调用，**执行前必须向用户说明目标与内容** |
| L4 数据 | 禁止外发原始明细，仅可发脱敏/聚合结果 |
| 任务 MCP | 建任务需写明责任方与验证方法 |
| 静默外发 | **禁止** —— 任何外发动作都要让用户知道 |

## 审计

每次数据访问记录：`{时间, 主体, 对象, 操作, 范围, 结果}`，追加写入 `logs/audit-{YYYY-MM}.jsonl`。

## 红线

1. 只读账号不可绕过
2. 拦截后不得变换形式重试绕过
3. L4 数据不得未经脱敏外发
4. 审计日志不得覆盖或删除
