# sg-qa-render · 问数结果渲染

## 定位

每个数字都要有**出身证明** —— 用户看到的不仅是值，还有这个值的口径、来源与可信度。

## 渲染四件套

### ① 数据表 / 趋势图

- 列名用**业务中文名**（语义层 `displayName`，缺省时按上下文生成）
- 单位与量纲标注在表头
- 大结果集默认 500 行并说明截断规则
- 趋势图：时间轴连续、缺失点显式断开（不插值掩盖）

### ② 口径说明卡（必备）

```
┌─ 口径说明卡 ─────────────────────────────────────────┐
│ 指标：合格率 (ZB_C01)                                  │
│ 指标层级：L4 复合指标（原子/派生 → 复合）              │
│ 口径：合格量占总产量比重，分子分母各自先聚合后相除     │
│ 复合公式：(合格量 / 总产量)，SQL: SUM(合格量)/NULLIF(SUM(总量),0) │
│ 单位：% | 版本：v1 | 厂部：三钢闽光 | 粒度：日         │
│ 血缘：T_DWS_FACT_ZZGZ_ZG01 ← P_DWS_FACT_ZZGZ_ZG01     │
│       ← T_ODS_TMMBW19B3（轧机实绩）                   │
│       〔指标体系〕ODS→DWD→DWS→ADS→IND 全链路见 lineage │
│ 置信度：高 | 限制：不含试轧批次；未经质控（如适用）    │
└───────────────────────────────────────────────────┘
```

### ③ 本体血缘摘要

给**精简视图**（3~5 层关键点），附"查看完整链路"入口（转 `sg-ontology-core`）。

### ④ 置信度与数据限制

| 项 | 说明 |
|---|---|
| 置信度 | 高 / 中 / 低（依据：匹配置信度 + 是否过闸门 + 数据完整性） |
| 数据限制 | 排除项、覆盖范围、时间边界、口径版本 |
| 未过闸门 | 必须标注"未经质控"，不做确定性结论 |

## 成本域特殊规则（P0）

> **成本升降语义反转：升为坏、降为好**

| 表现 | 生产域 | 成本域 |
|---|---|---|
| 上升 | 绿色好 ↑ | **红色坏 ↑** |
| 下降 | 红色坏 ↓ | **绿色好 ↓** |

渲染时颜色、箭头、文案三处必须一致反转，并在表头标注"（成本指标：降为好）"。

## 异常标注

| 异常 | 标注方式 |
|---|---|
| 空值 / 缺数 | 显著标记 + 提示可能原因 |
| 偏离基线 | 标注偏离幅度 + 可跳转根因分析 |
| 双轮不一致 | 双值并列 + 差异量 + 提示核查 |
| 数据未就绪 | 显著提示"成本数据未就绪"，不展示旧值冒充当日值 |

### 渲染模板化（问数通道 · SA-G01 趋势模板 · 2026-10-29 复盘落地）

> **背景**：趋势 HTML 已有 SA-G01 结构化模板（参照 `skills/sg-trend-analysis` 同一模板）。Q1/Q2（L0/L1）问数命中模板则 **gen_report 单脚本渲染，免 profiling 步骤**，与同链断言一次完成。

- **命中条件**：单/多指标趋势 + 图，且数据已通过口径校验与质量闸门。
- **单脚本渲染**：直接套 SA-G01 模板（固定配色 / CSS / ECharts 数据注入），不重复做数据探查。
- **同链断言**：渲染同时跑 J1（双花括号零残留）/ J2（node --check）/ J3（桩运行 setOption=图表数、空序列=0），与渲染同链完成，不另起质量专家全流程。
- **降级**：L2+（Q3 归因）仍走 sg-quality 全量闸门，本模板化不适用。

## 工作流

1. 接收质量专家放行后的结果集 + 语义卡 + 血缘摘要
2. 判断域（生产 / 成本）→ 应用对应语义规则
3. 组装四件套
4. 异常项标注
5. 输出（Markdown / 图表，或交 `sg-report-composer` 落盘）

## 输出规范

- 结论先行：一句话说清"是什么、变了多少、可不可信"
- 四件套齐全
- 异常与限制显式标注，不藏在脚注

## 注意事项

1. **不美化数据** —— 不为好看而插值、平滑或截断不说明。
2. 未过闸门的结果必须标注，绝不冒充已质控结论。
3. 成本域语义反转三处一致（颜色 / 箭头 / 文案）。
4. 口径卡必须来自语义层、本体血缘与指标体系（三引擎）三方一致结果，不临时编写；复合指标公式须以指标体系 `expression` 的"先聚后除 + NULLIF"为准。
