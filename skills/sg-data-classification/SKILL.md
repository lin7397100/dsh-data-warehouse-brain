# sg-data-classification · 数据分级分类

## 定位

敏感数据的**定级器**：定级决定谁能看、怎么看、看多少。

## 分级标准

| 级别 | 名称 | 数据范围 | 管控要求 |
|---|---|---|---|
| **L4** | 核心敏感 | 日成本明细、成本中心成本、产品毛利、采购价格、供应商结算 | 限权白名单 + 脱敏 + **全量审计** |
| **L3** | 敏感 | 生产经营指标、工序消耗、能源数据、质量数据 | 限权访问 + 审计 |
| **L2** | 内部 | 产量、作业率、成材率等一般生产数据 | 内部可用 |
| **L1** | 公开 | 已对外发布的统计口径数据 | 无限制 |

**默认规则**：成本数据为敏感级（L4）；未明确分级的新表**按 L3 从严处理**。

## 敏感字段识别

| 类别 | 字段特征 | 处置 |
|---|---|---|
| 价格类 | 单价、金额、成本、毛利、结算价 | L4，默认脱敏（区间化或仅给相对值） |
| 供应商/客户 | 名称、代码、联系人 | L4，白名单可见 |
| 人员 | 工号、班组人员、绩效 | L4，脱敏 |
| 工艺参数 | 配比、关键工艺参数 | L3，限权 |

## 工作流（四步）

### Step 1 · 识别对象

表 / 字段 / 指标 / 报表 → 确定定级对象与范围。

### Step 2 · 判定级别

按分级标准 + 敏感字段特征判定；不确定时**从严**，并标注 `待复核`。

### Step 3 · 确定管控要求

| 级别 | 访问控制 | 脱敏 | 审计 |
|---|---|---|---|
| L4 | 白名单 + 审批 | 必须（区间化 / 相对值 / 聚合后） | 全量 |
| L3 | 限权 | 按需 | 记录 |
| L2 | 内部 | 否 | 抽样 |
| L1 | 无 | 否 | 否 |

### Step 4 · 落配置与标注

- 写入分级清单（表/字段 → 级别 → 管控要求）
- 在语义层与元数据中标注级别
- 报表/看板生成时自动带上级别标注

## 脱敏方式

| 方式 | 适用 | 示例 |
|---|---|---|
| 聚合化 | 数值类 | 明细 → 按月/按工序汇总 |
| 区间化 | 单价类 | 3250 元 → 3200~3300 元 |
| 相对化 | 对标类 | 绝对值 → 与基准的百分比 |
| 遮挡 | 名称类 | 供应商 A** 有限** |

## 输出规范

```json
{"object": "SMBB_M_S_CB00.T_成本中心成本", "level": "L4",
 "reason": "含成本中心明细成本与单价",
 "controls": {"access": "白名单+审批", "masking": "聚合化/区间化", "audit": "全量"},
 "sensitive_fields": ["UNIT_PRICE", "COST_AMT"],
 "review_status": "已确认|待复核"}
```

## 注意事项

1. **从严判定** —— 拿不准就按高一级处理。
2. 成本明细禁止在对话中明文展开，必须聚合或脱敏后呈现。
3. 分级变更需记录版本与原因，并同步语义层与元数据。
4. 外部推送（通知 MCP）前必须复核级别，L4 数据不得外发原始明细。
