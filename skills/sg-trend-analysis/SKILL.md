# sg-trend-analysis · 趋势分析

## 定位

回答"在往哪个方向走、走得稳不稳、会不会持续"。

## 分析方法

| 方法 | 适用 | 说明 |
|---|---|---|
| 环比 | 短期变化 | 较上一周期（日/周/月） |
| 同比 | 消除季节性 | 较去年同期 |
| 移动平均（MA7/MA30） | 平滑噪声 | 看清主趋势 |
| 累计进度 | 目标管理 | 月累计 vs 月计划 |
| 季节性分解 | 有周期规律 | 趋势 + 季节 + 残差 |
| 线性/指数外推 | 短期预测 | **必须给置信区间** |

## 工作流（四步）

### Step 1 · 确定序列

指标 + 维度（厂部/产线/炉座/成本中心）+ 时间粒度 + 区间（默认近 30/90 天）。

### Step 2 · 取数并检查连续性

- 数据点是否连续（缺失日期显式标记，**不插值填补**）
- 是否有口径变更（版本切换点必须标注，否则趋势断裂是假象）

### Step 3 · 分析

1. 计算环比 / 同比 / 移动平均
2. 识别**拐点**（变化率符号翻转且幅度超阈值）
3. 判断持续性：连续 N 期同向变化才算趋势，单期波动是噪声
4. 与业务事件对齐（检修、限产、品种切换、原料变更）

### Step 4 · 结论与提示

| 结论类型 | 表述要求 |
|---|---|
| 趋势方向 | "近 7 日持续上升，累计 +5.2%" |
| 拐点 | "8 月 20 日起由升转降，与 2#高炉检修时间吻合" |
| 异常点 | "8 月 15 日单点突降 30%，疑为数据缺采（当日 ODS 未抽取完成）" |
| 外推 | "按近 30 日趋势，下月预计 X（区间 A~B，置信 80%）" |

## 常见陷阱

| 陷阱 | 表现 | 防御 |
|---|---|---|
| 口径变更假趋势 | 版本切换导致数值跳变 | 标注版本切换点，分段分析 |
| 季节性误判 | 把季节波动当趋势 | 用同比消除季节性 |
| 基数效应 | 低基数导致高增速 | 同时给绝对值与增速 |
| 缺失值插值 | 用插值掩盖缺数 | 不插值，显式断开 |
| 样本过短 | 3 个点就下结论 | 至少 7 个连续点，标注样本量 |

## 输出规范

- 趋势结论（方向 + 幅度 + 持续性 + 拐点）
- 支撑数据（序列 + 移动平均 + 同比/环比）
- **样本量与限制说明**（缺失点、口径变更、样本长度）
- 外推时给置信区间与失效条件

## 注意事项

1. **不插值掩盖缺数** —— 缺失就是缺失，断开显示。
2. 外推必须给区间与假设条件，不承诺点预测准确。
3. 成本域语义反转：成本"上升趋势"是负面信号，结论措辞必须体现。
4. 趋势结论必须与业务事件对齐验证，避免纯数据推断。
