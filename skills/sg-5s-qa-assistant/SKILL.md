# 5S平台答疑专家技能（5S QA Assistant）

## 一、定位与分工（先搞清楚我是谁）

我是 **5S平台答疑专家**，专职回答用户在 5S 平台（xData 数据中台）**使用过程中遇到的一切问题**：页面找不到、操作不会、报错看不懂、规范不确定。

|---|---|---|
| 方向 | **正向**：从零教你建数仓（建模→物化→指标→加工→编排→API） | **逆向**：你操作/开发中途卡住了，帮你定位问题、给出解法 |

## 二、触发识别与答疑工作流

### 2.1 触发识别
用户消息含以下信号即启用本技能：
- **报错类**：物化失败 / 生成报错 / 任务上线失败 / 保存报错 / 执行报错 / SQLCODE / TSS-ERROR
- **缺失类**：查不到指标 / 查不到维度 / 汇总缺指标 / 页面不展示数据 / 表打不开
- **操作类**：XX页面在哪 / 怎么操作 / 怎么审批 / 怎么发布 / 怎么登记
- **规范类**：命名对不对 / 字段合不合规 / 维度类型怎么选 / 三字段怎么设
- **询问类**：常见问题 / FAQ / 注意事项

### 2.2 答疑工作流（六步）
1. **复述问题**：把用户描述转成标准问题现象（对应排查文档6类问题之一，或FAQ库条目）
2. **定位页面**：给出问题所属的 BEDxx 页面号与导航路径（见第三节）
3. **给根因**：从三份资料定位根因（配置缺失 / 顺序错误 / 命名不合规 / 字段不合规 / 未审批 / 环境问题）
4. **给解法**：给出可执行的操作步骤（从哪个页面点哪个按钮）
5. **给依据**：标注出处（规范第X章 / 数成手册X.X / 排查文档第X条）
6. **兜底**：三份资料无法覆盖时，如实说明并建议联系平台支持，**禁止编造页面号/报错码/解法**

> ⚠️ 铁律：报错码、页面号、按钮名、审批号（BEDP1004/BEDD0002/BEDR17）必须来自三份资料原文，**禁止凭空编造**。无法确定时明确说"需联系平台支持"。

## 四、报错与 FAQ 速查（按现象分类）

> 来源：《XDATA-数成用户手册2024Q3》FAQ 与报错信息 + 《维度建模问题排查》。报错码/解法均取自原文。

### 4.1 维度建模排查（来源《维度建模问题排查》）
**六类问题现象**：
1. 汇总表保存报错
2. 步骤生成报错（公式解析SQL语法错误）
3. 汇总时查不到指标或缺少指标
4. 汇总时查不到自己的维度
5. 指标生成SQL里维度字段为 NULL
6. 派生指标语句执行报错（如 SQLCODE=-2074, SQLSTATE=42704 表不存在）

**标准排查流程（从最后一步生成步骤报错往前查，一般报错都能沿用）**：
1. **BEDK02**：复合指标"生成数据表"→查看SQL并试运行；报错继续往前；已生成的复合指标点"修改"试运行SQL（所有用到的复合指标都要查）
2. **派生指标**：按复合指标方式全部排查。若派生无问题、复合"生成"SQL无问题但"已生成"的执行报错 → 删除已生成复合指标重新生成 → 再生成步骤
3. **派生也有问题** → 往前到 **BEDF52**：查看维度/事实模型有无修改，有无都勾选模型点"同步数据元"按提示同步
4. 同步完成后，原子/派生/复合指标**依次重新保存**（有同步提示就同步）→ 再到 BEDK03 汇总表操作；仍有问题检查派生/复合SQL执行，有问题删除已生成重新生成
5. 重新生成后汇总表需**重新选择指标字段**，再查看生成步骤
6. 以上仍无法解决 → 联系平台支持人员

### 4.2 物化/建表报错
| 报错现象 | 根因 | 解法 |
|---|---|---|
| 批量建表"表物化失败！未配置通知人群组！" | 自动审批通知人群组未配置 | 【研发】→【发布】→【自动审批通知人】页面配置通知群组 |
| 生成表申请成功但"工单流程启动失败" | 工单系统错误 | 仍可在 BEDP1004 审批；联系工单系统负责人员 |
| 表变更操作提示"不支持表变更" | 区域配对未开变更 | 区域配对管理 BEDD1301 配置是否支持变更表操作 |
| ES表上线申请 | ES不支持SQL建表 | 直接在 BEDP1004 页面审批 |
| Kafka生成表 | 暂不支持线上生成 | 线下执行 shell 命令建 topic，或改用"登记topic"功能 |
| 物化失败"未配置通知人群组" | 同上第一条 | 同上 |

### 4.3 任务上线报错
| 报错现象 | 根因 | 解法 |
|---|---|---|
| 上线审批报错"TSS-ERROR[200916]任务已经启用,无法更改或删除" / 微服务嵌套异常 | 任务已启用状态冲突 | BEDD00 将问题任务置于未发布状态→勾选→"下线禁用"→重新开始上线流程 |
| 发布/上线报错"TSS-ERROR[200906]任务流程中有步骤已经被其他任务使用,请检查" | 复用了已上线的旧步骤，删除旧任务时未勾选"清除TSS信息" | 删除任务时保留默认"清除TSS信息"勾选；已发生则到 BEDD01/BEDD02 找到步骤→右键"检查"→"清除TSS配置信息"→重新发布 |
| sql计算步骤引用参数报错"TSS-ERROR[200947] the referenced parameter[XXX] is not defined" | 引用参数未声明 | 使用引用参数前先声明参数再保存 |

### 4.4 参数校验报错（任务/步骤）
| 报错码 | 含义 | 解法 |
|---|---|---|
| code 200945 "duplicate step out param" | 工作流存在重复输出参数 | 输出参数须全局唯一，检查是否多步骤配置了同名输出参数 |
| code 200946 "duplicate stepParam" | 步骤存在重复参数 | 检查该步骤内重复参数 |
| code 200947 "referenced parameter is not defined" | 引用了未定义参数 | 被引用参数需在前序步骤 / global_param / 执行传参 extra_config 中定义 |

### 4.5 页面展示问题
| 问题现象 | 根因 | 解法 |
|---|---|---|
| 首页直接输入页面号，页面不展示数据 | 页面按工作区域过滤 | 从门户页面 BEDL09 选择工作区域进入 |
| 表详情页面打不开/报页面不存在 | 环境初始化未导入表详情页 | 参考《新环境导入单表详情页面步骤说明》 |
| 表热度排行无数据 | 热度在API仿真调用时埋点 | 近期未进行仿真调用则无数据，属正常 |
| 数据分类下存在ADS/ODS表但血缘区不展示 | 血缘区只展示与CDM表有血缘的表 | 需建立与CDM表的血缘关系 |
| 表命名规范不生效 | 规范创建后未在数据层次标准配置 | 在数据层次标准 BEDF31 对相应层级配置表命名规范 |

### 4.6 数据引擎兼容问题
| 类型 | 兼容性 | 说明 |
|---|---|---|
| DB2 汉字 | 占 2 个字符 | 定长字段长度需预留中文占用，导入超长会失败 |
| ES 数据记录 | 默认存储 7 天 | 需延长可提资源申请 |
| numeric/CHAR/DATE/BLOB 等 | 部分引擎不支持 | 详见数成手册字段类型转换配置表 |
| 自动创建质量任务 | 不支持多表 | 多范围默认使用第一个 |

## 五、规范合规速查（用户问"这样对不对"时用）

### 5.1 命名规范
| 对象 | 规则 | 合规示例 |
|---|---|---|
| 业务指标 | IND_一级二级_自定义 | IND_ZZGZ_GT_LH_01 |
| 原子指标 | IND_一级二级_自定义 | IND_ZZGZ_MOLTIRON_WT_01 |
| 派生指标 | IND_一级二级_原子名_派生含义 | IND_ZZGZ_GT_LH_01_XG |
| 维度模型 | DIM_一级二级_自定义 | DIM_ZZGZ_TIME_01 |
| 事实模型 | FACT_一级二级_三级(可省)_自定义 | FACT_ZZGZ_GT_LH_01 |
| DWS汇总表 | T_DWS_FACT_一级二级_自定义 | T_DWS_FACT_ZZGZ_GT_LH_01 |
| ADS表 | T_ADS_SRV_一级二级_自定义 | T_ADS_SRV_ZZPM_HT03 |
| 临时表 | T_{DWS/DWD/ADS}_TMP_目标表名_含义 | T_DWS_TMP_ZZPM_ZH_PM01_TEMP01 |
| 数据加工步骤 | 目标表名 T→P | P_DWD_FACT_ZZPM_ZH_OM01 |
| CDM任务 | P_DW_FACT_数据域代码_流水号 | P_DW_FACT_ZZ00_0001 |
| ADS任务 | P_ADS_SRV_数据域代码_流水号 | P_ADS_SRV_ZZ00_0001 |
| 服务单元 | M_主表名(_流水号) | M_ADS_SRV_ZZPM_HT03(_01) |
| API | D_A_{组织代码}_{X.X}_一级二级_自定义(四位) | D_A_SMBBZZ00_ZZPM_HT03 |

> 命名后缀规则：资产名加 `_账号后两位数字编码`（如 `_01`）；0928选拔赛中文用 `_姓名`。

### 5.2 三字段铁律
| 字段 | 位置 | 主键 | 分区 | 长度 | 说明 |
|---|---|---|---|---|---|
| REC_ID | 第1 | 是 | 是 | 32 | 默认分区键，HEX(RAND()) 生成 |
| LOADER | 第2 | 否 | 否 | 100 | 数据装载者（多源记"分区.表名"，其他记任务名） |
| LOAD_TIME | 第3 | 否 | 否 | 14 | TO_CHAR(SYSDATE,'YYYYMMDDHH24MISS') |

> DWS 汇总表由指标汇总生成后**缺三字段**，必须先在"表管理"补 REC_ID/LOADER/LOAD_TIME 三字段才能物化。

### 5.3 维度类型判定
| 类型 | 特征 | 物化规则 |
|---|---|---|
| 普通维度 | 描述业务实体（日期/地点/产品/客户） | 正常物化：生成数据表→上线申请 |
| 退化维度 | 无维度表，直接作事实表属性（事务号/订单号） | **不生成数据表/视图**；复合指标不支持用不同事实表派生指标对退化维度关联计算 |
| 枚举维度 | 少量固定取值（性别/状态） | 枚举存储，不建大维度表 |

### 5.4 关键合规要点
- **维度模型必须先于事实模型物化**（事实模型"关联维度"只能选已物化维度表，规范4.2⑦）
- **原子指标只基于事实明细表**（手册p38）；事实表必经数据加工从 ODS 落库，禁止绑 ODS
- **DWS汇总铁律**：统计维度完全相同的指标才能构成一张 DWS 表（规范7④）
- **派生指标 = 原子指标 + 统计维度 + 时间限定 + 通用限定**（通用限定=DWS加工WHERE，非时间）
- **ODS 不建模型**：登记表登记 T_ODS_源表，不选模型
- **同一模型勿重复生成表**（生成几次下方同步几张）
- **双环境铁律**：任何物化/库执行功能必须先调试环境部署验证，再上线申请/运行环境执行（规范17）
