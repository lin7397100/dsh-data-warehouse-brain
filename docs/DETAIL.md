# 数仓智脑专家团

把一套**数据仓库智能体团队**装进 DSH：一个主理人带 22 位专家，外加一个快问车道、65 个技能和一个侧边栏看板。

## 功能

- **24 个 Agent preset**：装完即可在会话里选到「冶衡 · 首席数仓编排师」。主理人只做拆解、派发与验收，不取数、不写 SQL；专家各守一块：语义层、本体、元数据与血缘、SQL 编译、质量与根因、可视化、治理、指标构建、5S 开发与答疑、成本域、生产域。
- **65 个技能**（`sg-*`）：随包提供，经 `bundledSkillDir` 挂给每个 preset，不需要手工复制到技能目录。覆盖意图路由、DSL 编译、物化直查、血缘穿透、根因分析、质量规则、看板与报告、EPLAT 5S 设计态元数据等。
- **侧边栏看板**：左侧栏「数仓专家团」一行，内含专家名册、运行概览、路由记录、调度链路四个页签；数据只读，来自团队根下的本地文件与 SQLite 台账。
- **团队运行脚本**：闸门（判型/契约/新鲜度/静态检查/断言/跨源对拍）、台账与报表脚本随包提供，首次启动铺到团队根。

## 使用

1. 重启 DSH 后新建会话。
2. Agent 选择器选「冶衡 Axis · 首席数仓编排师」。
3. 直接说需求，例如：「查本周各工序炼钢成本，标出超定额项」「这个指标的数据质量规则和安全等级是什么」。
4. 左侧栏「数仓专家团」查看名册与调度链路。

## 已知限制

- 不包含知识语料（DDL、口径、语料约 36MB），依赖本地知识检索的技能会降级到 WeKnora / DB2 通道。
- 内网 MCP（WeKnora / DB2 / 企微）默认关闭，需设 `DWB_INTERNAL_MCP=1`。
- 运行时脚本需要 Python 3（`python` 或 `python3` 在 PATH，或用 `DSH_PYTHON` 指定）；缺依赖时相关步骤会降级而不是中断。
- 看板是只读投影：不写库、不改人设，只允许对覆盖层备注与 MCP 标量做备份后回写。
