# 断链兜底协议 · lineage_fallback（2026-11-02 新增 · E9）

> **依据**：第零铁律「全链路血缘贯通律」**推论 5**。
> **一句话**：反向追溯断链时，**禁止手搓、禁止静默出数**，必须走正向建模兜底，并显式标注置信度降级。

---

## 1. 触发条件（任一命中即启动）

| 断链形态 | 判据 |
|---|---|
| **A · SQL1 缺失** | `T_ADS_DIM_GZ01.SQL1` 为空 / 取不到 / 执行无结果 |
| **B · CREATER 缺失** | `CREATER` 字段为空，或 `SYSCAT.ROUTINES` 查无此过程 |
| **C · 加工逻辑不可解** | 过程正文为动态 SQL / CLOB 截断 / tmp 静态依赖残缺且无法补齐 |
| **D · 指标未注册** | 无 ZB_CODE、无口径，只有用户一段业务白话（→ 同时走 `caliber_check.md` L4） |
| **E · 血缘三闸门不过** | ①结构缺失 / ②链路断裂 / ③设计态-数据态不一致 |

**启动动作**：编排器在 trace 记 `lineage_fallback: true` + `fallback_reason: <A|B|C|D|E>`，**升型带链重派**，不得就地降级出数。

---

## 2. 三源补充（按优先级依次尝试，命中即停）

| 优先级 | 来源 | 取法 | 作用 |
|---|---|---|---|
| **S1** | **用户业务规则**（会话内自然语言 / 上传文档） | 直接采用；文档须含 **指标码 + 数值/口径 + 生效期** | 最权威，直接定口径 |
| **S2** | **weknora K4 业务规则库** `6838e00b-fb8e-4de3-9f08-425af71dbdbd` | `hybrid_search` 检索 `RULE-*` 文档 | 复用既有沉淀规则 |
| **S3** | **weknora K7 大数据5S平台知识库** `d12f3c32-bf50-41cc-8be8-77af4c45bb35` | `hybrid_search` 检索「指标开发全流程步骤 / 原子 派生 复合 / 数据分层」 | **建模方法论标准**（必查，未查即违规） |
| **S0 兜底** | 本地 `knowledge/5s/`（12 份） | Grep 分段读取 | K7 不可达时降级（记 `weknora_status=down`） |

> **S1 上传即用**：用户上传的规则文档本地落盘 `knowledge/design/rules/` 后**本次会话立即解析执行**，绝不白传。
> **S3 铁律**：正向建模前**必须先查 K7**；未查即建模 → 记违规，产物标 `[未依规范·存疑]`。

---

## 3. 正向建模六步（主责：`sg-metric-builder` 矩衡）

依据 K7 5S 规范，**从 ODS 层表开始正向构建**指标与血缘：

```
Step 1  定位事实明细表
        ODS 贴源表 T_ODS_*（需转换清洗）→ 确认 T_DWD_* 事实明细落点
        取证：weknora K1 表结构库 + DB2 SYSCAT.COLUMNS 实查
Step 2  定原子指标
        原子指标 = 来源于事实明细表 T_DWD（最小不可再分度量）
Step 3  套维度与口径（口径六要素）
        ① 度量单位 ② 统一口径(维度) ③ 通用限定条件
        ④ 计算逻辑 ⑤ 计算方式(求和/统计/求平均…) ⑥ 来源表
        维度取自 T_DIM_*（横切：厂别/产线/日期/钢种…）
Step 4  构建派生指标
        派生 = 原子 + 度量单位 + 统一口径(维度) + 通用限定条件 + 计算逻辑 + 计算方式
Step 5  构建复合指标（如需）
        复合 = 派生指标经 加减乘除 运算得来
Step 6  产出设计态血缘 JSON + 实据核验
        按标准血缘 JSON 输出 layers（ODS/CDM/ADS）+ gates + confidence
        能实查的部分必须实查对账；不能实查的显式留空并标注
```

**指标层级体系（标准 · 权威口径）**：

```
业务指标（用户视角，对应 ZB_CODE）
  ├─ T_DIM 维度表（横切各层：厂别/产线/日期/钢种…）
  └─ 事实明细表（ODS 贴源，需转换清洗）→ T_DWD
       └─ 原子指标（来源于 T_DWD）
            └─ 派生指标（原子 + 度量单位 + 统一口径(维度) + 通用限定条件 + 计算逻辑 + 计算方式）
                 └─ 复合指标（派生指标 加减乘除 运算得来）
```

---

## 4. SQL 准确性护栏（正向建模产物同样适用）

- **只允许写 DSL（声明式）**，最终可执行 SQL **必须**经 `sg-dsl-compiler` 编译；
- 过**三查**：① 语法 ② 表存在性 ③ 合理性；
- 过 `sg-quality` 可靠性闸门（非空 / 量级合理 / 同比环比可解释）；
- **禁止裸写裸出**（详见 `sg-adhoc-indicator` E11 条款）。

---

## 5. 置信度与标注规范（强制）

| 血缘来源 | 标注 | confidence 上限 | 可否作确定值 |
|---|---|---|---|
| **反向实据**（SQL1+CREATER+ODS 实查对账全通） | 无标注 | 0.95 | ✅ 可 |
| **反向部分**（缺一环但可对账） | `[血缘不完整·数据存疑]` + 缺失环 | 0.75 | ❌ 否，须说明 |
| **正向建模**（本协议产出） | **`[正向建模·待实据核验]`** | 0.60 | ❌ **否**，待固化+实据核验 |
| **未查 K7 的正向** | `[未依规范·存疑]` | 0.40 | ❌ 否，且记违规 |
| **三源皆缺** | `[无法查证]` | — | ❌ 否，如实说明+解锁路径 |

**混用禁令**：`[正向建模]` 血缘**不得与反向实据血缘混用置信度**；同一报告中二者必须分区呈现。

---

## 6. 固化回流（闭环，非可选）

正向建模产物经实据核验通过后，须回流固化：

1. `sg-semantic`（铨度）注册/更新语义层口径；
2. `sg-metric-builder`（矩衡）写入指标体系（version +1）；
3. 可选：同步 weknora K3 指标体系库 / K4 业务规则库（`create_knowledge_from_text`）；
4. `sg-memory`（铭枢）沉淀 `MEM-*` 记忆，供下次直接复用、不再走兜底。

**验收**：固化后重跑血缘三闸门，全通方可摘掉 `[正向建模·待实据核验]` 标注。

---

## 7. 违规清单（监衡 trace 校验项）

| 违规 | 判据 | 处置 |
|---|---|---|
| 断链静默出数 | trace 无 `lineage_fallback` 却标注了正向/存疑 | 结论作废 + 记违规 |
| 手搓近似血缘 | 交付物含非 JSON 来源的自撰链路 | 结论作废 + 记违规 |
| 未查 K7 即建模 | 正向建模 trace 无 K7 检索记录 | 标存疑 + 记违规 |
| 置信度混用 | 同一结论同时引用反向与正向且未分区 | 退回重做 |
| 兜底未回流 | 正向产物核验通过后 7 日内未固化 | 提醒 + 记待办 |
