### 🎯 任务类型判定规则（Q1-Q5 两步判定 · 2026-10-29 复盘落地 · 铁律级）

> **背景**：TR-20261029-1511-001 复盘发现，单指标近7日趋势走全链（6 专家齐发、82 分钟）纯粹是"判型无客观规则、默认拉全量入场"。本规则把判型变成可审计、可测的白名单，Q1/Q2 类（预计问数流量 70%+）默认零专家深审。

**第零步 · 域前置分流（先于 Q1–Q5 · 铁律 · 2026-10-30 修复）**：

> 🔴 **最高优先豁免：驾驶舱快线（2026-10-30 新增，优先级高于下列全部域关键词）**
> 命中 `驾驶舱报告 | 生产经营驾驶舱 | 生成驾驶舱 | 集团经营驾驶舱 | cockpit | 领导驾驶舱 | 集团经营总览` → **不再做域分流**，直接派 `sg-insight` 执行 `sg-cockpit-report`（四域聚合 + 36 闸门 + 四层下钻）。
> 理由：驾驶舱天然跨生产/成本/存货三域，若按 `成本`/`存货` 关键词拆成单域，会丢掉另外两域与标准成本对比模块。
> 判型：记为 **Q2（问数+报表）**，`fast_lane=false`，`qt_level=L1`；**禁止**因跨三域而升级为 Q3+/6 专家会诊。

判型前先按域关键词锁定数据域，**成本域/存货域禁止走 `T_ADS_DIM_GZ01` 判定无数据**。
- 命中 `成本|利润|边际贡献|保本线|科目构成|吨材成本|工序成本|轧制费|成材率|为什么贵` → `domain=cost`，**强制加载 `sg-cbprod-warehouse` v2、走成本域口径决策树（SIDE_COST / DAY_COST / PRODUCT_COST）**，禁止进通用 `T_ADS_DIM_GZ01` 问数路径。
- 命中 `库存|存货|存货日管控|库龄|周转天数|合理库存|异常库存|资金占用|库区分布` → `domain=inventory`，走 K7（指标口径）+ K2（加工逻辑）+ K1（表结构），禁止查 `T_ADS_DIM_GZ01` 判定无数据；**未注册 ≠ 不可用**，按 `caliber_check.md` 走 L2→L5 回退链。
- 命中 `生产|高炉|转炉|轧线|产量|铁水|钢坯|能源` → `domain=prod`，走 `T_ADS_DIM_GZ01` + GZPROD 主链路。
- 均未命中 → 默认 `domain=prod` 通用问数。
> 边界：`T_ADS_DIM_GZ01` 仅覆盖生产管制/能源/销售类；成本域在 CBPROD 表、存货日管控在 ZZCH 表，**禁止以 GZ01 无指标判定成本/存货无数据**。

**第二步 · 模型一票（规则未命中时，仅 1 次调用，4 分类）**：意图置信度 < 0.8 才升格，且必须给出**判据字符串**写入 trace。

**⚖ Q6 优先于 Q1/Q2 禁止派单（2026-11-05 P1-7 新增）**：Q6 为**建设/治理元任务**，不产生取数流量。当用户诉求同时命中 Q1 触发词（"查/看"）与 Q6 触发词（"语义层/本体建模/指标构建/评测回归/口径咨询"）时，**优先判 Q6**——因为用户意图是「建设/维护语义资产」而非「查数」。Q6 豁免 Q1/Q2 禁止派单列表，可正常派 `sg-development`/`sg-quality`/`sg-governance`。

**Q1/Q2 禁止派单列表（铁律）**：`sg-development` / `sg-quality` / `sg-governance` / `sg-root-cause-fullchain` / `sg-quality-rule-gen` 在 Q1/Q2 下**一律不派发**；问数走「KB 检索 + 快车道 + 模板渲染」单链路。Q6 元任务不受此限制。

**Trace 三字段必填（监衡硬规则）**：每个任务 trace 必须写入 `task_type`（Q1-Q5）+ `fast_lane`（bool）+ `qt_level`（L0-L3）；**三字段缺一 → 监察驳回重派**。

**⚖ 与既有「多基地/跨厂」触发的优先级（2026-10-29 审计补齐 · 消解冲突）**：本 Q1-Q5 判定**优先**于全文任何「多基地/跨厂对比 → 强制组队多专家 / 3 专家双盲 / 严禁走快速路径」的通用触发（含「多专家协同最低触发条件」中的『多基地对比（≥2 基地）→ §13.2 双盲交叉 3 专家』，以及「快速路径适用范围」中的『涉及多基地/跨厂对比…必须组队多专家』）。**纯问数 / 趋势 / 数值对比（无根因、无排名对标诉求）即便跨 ≥2 基地，一律走 Q1/Q2 快车道单链路 + 单条批查（三基地合一 SQL），不拆分母专家**；上述「多基地 → 3 专家双盲」与「严禁快速路径」两条仅在用户**显式要求『对标排名』**或判型为 **Q3+（归因/建模/治理）** 时生效。跨域会诊（GZPROD+CBPROD → 6 专家）按关键词原规则保留不变。
